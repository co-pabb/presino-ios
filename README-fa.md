# پرزینو برای iPhone — ساخت فایل ipa بدون مک

این پروژه یک پوسته‌ی iOS است که presino.ir را باز می‌کند و دو چیز اضافه دارد:
- موقعیت (GPS) یک‌بار برای کل برنامه پرسیده می‌شود، نه برای هر باز شدن سایت.
- خروج خودکار با ژئوفنس سیستم‌عامل؛ حتی وقتی برنامه بسته است کار می‌کند.

## مراحل (حدود ۲۰ دقیقه، یک‌بار)
1. در github.com حساب رایگان بسازید.
2. **New repository** بزنید، نام دلخواه، گزینه‌ی **Public** (برای ساخت رایگان و نامحدود؛ در این پروژه هیچ رمزی نیست).
3. فایل zip را روی لپ‌تاپ باز کنید و **همه‌ی محتویات** را (شامل پوشه‌ی `.github`) با **Add file ← Upload files** آپلود و **Commit** کنید.
   اگر پوشه‌ی `.github` آپلود نشد: **Add file ← Create new file**، نام را `.github/workflows/ios.yml` بگذارید و متن فایل `ios.yml` را در آن کپی کنید.
4. تب **Actions** ← «Build iOS ipa» ← **Run workflow**. حدود ۱۰ دقیقه طول می‌کشد.
5. بعد از تمام شدن، پایین صفحه‌ی همان اجرا، بخش **Artifacts** ← `Presino-ipa` را دانلود کنید. داخلش `Presino-unsigned.ipa` است.
6. همین فایل را در پنل توسعه‌دهنده‌ی سیب‌اپ آپلود کنید.

## نکته‌ها
- فایل امضا نشده است. اگر سیب‌اپ فایل امضانشده را نپذیرفت، بگویید تا مرحله‌ی امضا اضافه شود (حساب توسعه‌دهنده‌ی اپل لازم می‌شود).
- بار اول که برنامه موقعیت می‌خواهد، گزینه‌ی **Allow While Using** و بعد **Change to Always Allow** را بزنید؛ بدون «Always» خروج خودکار در پس‌زمینه کار نمی‌کند.
- برای هر نسخه‌ی جدید، در `project.yml` مقدار `CURRENT_PROJECT_VERSION` را یکی زیاد کنید.

## نسخه ۴ (آبان ۱۴۰۵)
- صفحه‌ی اول کارمند به طرح «آسمان کار» تغییر کرد (ساعت و کمان شیفت، خورشید، دکمه‌ی «۱ ثانیه نگه دارید»، چهار گوی، «روز من»، آخرین درخواست‌ها) و در حالت روشن/تیره مثل وب است.
- این نسخه به API سرور نیاز دارد: بسته‌ی group254_ios_home_api (فیلد today_readable) را روی سرور نصب کنید.
